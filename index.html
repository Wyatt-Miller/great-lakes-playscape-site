Who we are

A family business, built for local families

Great Lakes Playscape is owned and run by Wyatt & Claire Miller, a husband-and-wife team with backgrounds in education, child development, youth programming, and financial operations. We started this because we saw the same thing so many North Shore parents already know — long winters mean too few indoor places for kids to really run and play. So we're building the one we wished we had.
